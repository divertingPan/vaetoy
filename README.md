## 1. 核心概念说明

- **Encoder（编码器）** 的作用是：输入一张现成的图像（16x16），将其压缩为一个 8 维的潜空间向量 $z$。
- **Decoder（解码器 / 生成器）** 的作用是：输入潜向量 $z$，将其解码还原并**生成** 16x16 的图像。

因此，在我们的单片机实体玩具中：
1. 当你按下数字键（例如按键 `5`）时，单片机会调出数字 5 对应的潜空间坐标 $z_5$（在训练时计算出的锚点 `anchor`）。
2. 在旧数字向量与新数字向量之间做平滑插值（Ease-in-out Smoothstep）。
3. Decoder 实时计算输出 16x16 的像素亮度，点亮 LED 点阵。

## 3. 接线方案详解

### 3.1 WS2812B 点阵屏接线 (仅需 3 根线)
点阵屏背后自带三根线：
- **5V / VCC**（红线） $\rightarrow$ 连接 ESP32-S3-CAM 开发板的 **5V** 引脚（左侧排针 Pin 20）
- **GND**（黑线） $\rightarrow$ 连接开发板的 **GND** 引脚（右侧排针 Pin 20）
- **DIN / DATA**（绿线/白线） $\rightarrow$ 连接开发板的 **GPIO 21** 引脚（右侧排针 Pin 17）

> **注意供电安全**：代码中已将点阵亮度上限限制为 `40`（总满亮为 255）。室内清晰明亮且整个屏幕耗电仅约 200~300mA，电脑 USB 接口（500mA 上限）完全能够稳定带起，无需外接额外电源。

### 3.2 10 个机械按键接线 (0 ~ 9)
**10 个按键引脚全部集中在开发板左侧排针的 Pin 3 到 Pin 12 连续一字排开** 

每个机械轴体底部有 2 个金属引脚：
1. **公共引脚**：将 10 个轴体的其中一个引脚全部连到开发板的 **GND**（右侧排针 Pin 20）。
2. **信号引脚**：将 10 个轴体的另一个引脚，按顺序插到左侧排针连续 10 个引脚：

| 按键数字 | 板上物理排针位置 | ESP32-S3 GPIO 引脚 | 说明 |
| :---: | :---: | :---: | :--- |
| **0** | **左侧排针 Pin 3** | **GPIO 4** | 内部弱上拉，按下接通 GND 低电平有效 |
| **1** | **左侧排针 Pin 4** | **GPIO 5** | 内部弱上拉，按下接通 GND 低电平有效 |
| **2** | **左侧排针 Pin 5** | **GPIO 6** | 内部弱上拉，按下接通 GND 低电平有效 |
| **3** | **左侧排针 Pin 6** | **GPIO 7** | 内部弱上拉，按下接通 GND 低电平有效 |
| **4** | **左侧排针 Pin 7** | **GPIO 15** | 内部弱上拉，按下接通 GND 低电平有效 |
| **5** | **左侧排针 Pin 8** | **GPIO 16** | 内部弱上拉，按下接通 GND 低电平有效 |
| **6** | **左侧排针 Pin 9** | **GPIO 17** | 内部弱上拉，按下接通 GND 低电平有效 |
| **7** | **左侧排针 Pin 10** | **GPIO 18** | 内部弱上拉，按下接通 GND 低电平有效 |
| **8** | **左侧排针 Pin 11** | **GPIO 8** | 内部弱上拉，按下接通 GND 低电平有效 |
| **9** | **左侧排针 Pin 12** | **GPIO 3** | 内部弱上拉，按下接通 GND 低电平有效 |

> **极度整洁**：从 Pin 3 到 Pin 12 连续 10 根针脚无间隔连插，无需外接任何上下拉电阻。

## 4. 权重转换说明

**无需手动做任何模型转换，直接上传即可！**

1. 训练脚本 `train_vae.py` 在训练完成时，已经自动生成了定点化 C 数组文件。
2. 推荐直接使用工程目录：[`mcu_code_main_standby`](mcu_code_main_standby)。
3. 文件夹内包含：
   - [`mcu_code_main_standby.ino`](mcu_code_main_standby/mcu_code_main_standby.ino)：主控流程（潜空间高斯随机采样、WS2812 驱动、串口免接线调试）。
   - [`mcu_code_vae_engine.h`](mcu_code_main_standby/mcu_code_vae_engine.h) 与 [`mcu_code_vae_engine.cpp`](mcu_code_main_standby/mcu_code_vae_engine.cpp)：专为单片机优化的纯 C++ VAE 前向推理引擎（引入硬件随机数生成器）。
   - [`mcu_code_decoder_weights.h`](mcu_code_main_standby/mcu_code_decoder_weights.h)：当前训练好的 VAE 权重、均值锚点与离散分布标准差。
4. **如果后续重新训练了模型**：只需重新运行训练即可， `decoder_weights.h` 权重会自动更新过去。

## 5. ESP32-S3-CAM 手把手烧录教学

### 第一步：安装 Arduino IDE
下载安装 [Arduino IDE 官方版](https://www.arduino.cc/en/software)。

### 第二步：安装 ESP32 芯片支持包
1. 打开 Arduino IDE，点击菜单：**文件 (File) $\rightarrow$ 首选项 (Preferences)**。
2. 在 **其他开发板管理器网址 (Additional boards manager URLs)** 填入：
   ```text
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. 左侧工具栏打开 **开发板管理器**，搜索 `esp32` 并安装 **esp32 by Espressif Systems**。

### 第三步：安装 FastLED 库
左侧工具栏打开 **库管理器**，搜索 `FastLED` 并安装。

### 第四步：双 Type-C 接口连接与配置（重要！）
ESP32-S3 底部有两个 Type-C 接口：
- **`TTL` 口**：板载 CH340 串口芯片（推荐新手使用此口，简单稳定）。
- **`OTG` 口**：ESP32-S3 芯片原生 USB 接口。

1. **推荐用 USB 线插在 `TTL` 口**：
   - 顶部菜单 **工具 $\rightarrow$ 开发板 $\rightarrow$ esp32 $\rightarrow$ ESP32S3 Dev Module**。
   - 顶部菜单 **工具 $\rightarrow$ USB CDC On Boot**：保持 **Disabled**。
   - 顶部菜单 **工具 $\rightarrow$ Flash Size**：选 **8MB**（或根据板子实际选 16MB）。
   - 顶部菜单 **工具 $\rightarrow$ PSRAM**：选 **OPI PSRAM**（或 Disabled，我们模型轻量，片内 512KB SRAM 已经足够）。
   - 顶部菜单 **工具 $\rightarrow$ 端口 (Port)**：勾选识别到的 COM 口。
2. **如果插在 `OTG` 口**：
   - 顶部菜单 **工具 $\rightarrow$ USB CDC On Boot**：必须设为 **Enabled**（这样 `Serial` 打印才会重定向到 OTG 接口）。

### 第五步：一键编译与烧录
1. 用 Arduino IDE 打开 [`mcu_code_main_standby/mcu_code_main_standby.ino`](mcu_code_main_standby/mcu_code_main_standby.ino)。
2. 点击左上角 **上传 (Upload)** 箭头按钮。
   > *小技巧*：如果控制台出现 `Connecting......____`，按住开发板上的 **BOOT** 按钮 1~2 秒直到开始显示上传百分比即可松手。
3. 烧录完成后打开串口监视器（波特率 115200），输入数字 0~9 即可提前验证点阵屏！

## 6. 调试与常见问题排查

### 6.1 免接按键测试（极速验证）
即便你还没买按键或者还没插杜邦线，也能测试！
1. 点击 Arduino IDE 右上角的 **串口监视器 (Serial Monitor)** 图标（放大镜形状）。
2. 右下角波特率设置为 **115200**。
3. 在顶部输入框输入任意数字 `0` 到 `9` 并按回车。
4. 你会立即看到点阵屏上流畅地变幻出对应的数字，串口打印：`[SERIAL CMD] 收到指令: 5`。

### 6.2 点阵图像镜像或倒立怎么办？
市面上不同的 16x16 矩阵焊线方向可能不同。打开 [`mcu_code_main_standby.ino`](mcu_code_main_standby/mcu_code_main_standby.ino)，找到第 106 行的 `XY` 函数：
```cpp
uint16_t XY(uint8_t x, uint8_t y) {
    if (x >= MATRIX_WIDTH || y >= MATRIX_HEIGHT) return 0;
    
    // 如果上下颠倒，取消下面这行的注释：
    // y = 15 - y;
    
    // 如果左右相反，取消下面这行的注释：
    // x = 15 - x;

    if (y & 0x01) {
        return (y * MATRIX_WIDTH) + (MATRIX_WIDTH - 1 - x);
    } else {
        return (y * MATRIX_WIDTH) + x;
    }
}
```
保存后重新上传即可瞬间纠正方向！
